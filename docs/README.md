## 这一张的两个已知瑕疵（都没修，如实留档）

1. 🔴 **图里混了中英两种语言**：面板是**英文**（`Relevant` / `Docs` / `Fullscreen` /
   `Open locally` / `Referenced by …`），但文档行右边的相对时间显示的是**中文**
   `3 分钟前`。原因是**那串时间文案在客户端里是硬编码中文**，没进 `ZH` / `EN` 词典 ——
   `knit/src/client/client.js` 的 `relTime()`（第 888 行起：`'刚刚'` / `${min}分钟前` /
   `${hour}小时前` / `'昨天'` / `${day}天前` / `${m}月${d}日`，整段没有 `t()`）。

   扫过整个客户端后确认：**词典之外只有三处裸中文**，其余文案全部走 `t()`
   （所以这三处是例外，不是惯例）：

   | 位置 | 文案 | 影响面 |
   |---|---|---|
   | `relTime()`，第 891–899 行 | `刚刚` / `X分钟前` / `X小时前` / `昨天` / `X天前` / `X月X日` | **英文界面下用户直接看见**（这张截图里就是） |
   | 列表容器的 `aria-label`，第 1717 行 | `最近文档` | 读屏用户；界面上看不见 |
   | better-sidebar 的 tab 标题，第 2256 行 | `Knit 最近文档` | 只在装了 `dsh-better-sidebar` 时可见 |

   违反 `AGENTS.md` §4.5「不要在任何地方硬编码面向用户的文案」。
   **`test/i18n.test.mjs` 抓不到它** —— 那个守卫查的是「两边键集一致 / 占位符对齐 /
   错误码有翻译」，不会去扫组件代码里的裸字符串。
   **这是被这张截图暴露出来的真实缺陷，不是截图问题。**
2. ⚠️ **一处系统提示气泡挡住了列表里的一行**：`打开 DeepSeek Harness` 压在
   `Knit PRD · v0.12 …` 那一条上（Dock/taskbar 的悬停提示被一起截进来了）。

> 两条都**不影响这张图当第 1 屏用**（引用条看得清清楚楚），
> 但**下次重拍时应该都消失**：先修 i18n 那条，再关掉悬停提示重拍。

## ⚠️ 这张图在哪儿能看见、在哪儿看不见

| 面 | 能不能看见 | 为什么 |
|---|---|---|
| GitHub 仓库首页 | ✅ | README 里的相对路径 `docs/screenshot.png`，文件就在仓库里 |
